# Product Documentation

This directory is the source of truth for durable product behavior, supported user flows, and
explicit product boundaries. Implementation ownership belongs in the
[architecture overview](../architecture/README.md), component setup in module READMEs, and
knowledge-production operations under [`docs/knowledge`](../knowledge/README.md).

- [Patcher and Minecraft mod](patcher-and-minecraft-mod.md) defines the desktop patcher, instance-local runtime, scheme behavior, MCP surface, and in-game UX.
- [First-party knowledge packs](first-party-knowledge-packs.md) defines exact-fingerprint support, evidence and trust guarantees, and runtime knowledge behavior.
